# Local Delivery, Images & Docs

**Scope**: "it builds, it ships, it's documented" — all local; no GitHub Actions/GHCR/Pages. Not here → `zaolang-remote-deploy` (prod box), `zaolang-testing-qa` (test layers).

## Key Paths

| Path | What |
| --- | --- |
| `Makefile` | `check`, `lint`, `format`, `hooks`, `openapi`, `openapi-check`, `docs`, `docs-build`, `release-up` |
| `.pre-commit-config.yaml` | ruff, mypy, prettier, eslint, tsc, messages, openapi-drift + stock hygiene hooks (`check-added-large-files` 512KB) |
| `back/pyproject.toml` | ruff (per-file ignores), mypy, pytest markers |
| `front/eslint.config.mjs`, `front/.prettierrc.json`, `front/.prettierignore` | front lint/format; vendored `front/public/wasm/opencut/` ignored by both |
| `front/scripts/check-bundle-size.mjs` | `test-front` bundle gate vs committed `front/scripts/bundle-budget.json` |
| `back/Dockerfile` | one image for api/worker/poller/beat/migrate: venv builder stage; runtime has ffmpeg + `postgresql-client-17` (PGDG) |
| `front/Dockerfile` | web image (`output: 'standalone'` in `front/next.config.ts`); `NEXT_PUBLIC_API_URL`/`APP_VERSION` are build args |
| `infra/docker-compose.release.yml` | one-command local demo |
| `mkdocs.yml` | docs site, `strict: true`, `nav` |
| `docs/` | site pages; `docs/openapi.json` is generated from `back/openapi.json` (gitignored) |
| `third_party/opencut-classic/` | vendored MIT Rust workspace that rebuilds `front/public/wasm/opencut/` (`wasm-pack build rust/wasm --target web`) |

## Invariants

1. `make check` = `lint typecheck messages openapi-check test` (`test` = `test-back` + `test-front`). It is the only gate; anything needing a seeded DB (e2e/a11y/visual) stays a separate target.
2. `make lint` = `ruff check` + `ruff format --check` (back) and `npm run lint` + `npm run format:check` (front). Both trees are format-clean — one unformatted file turns `make check` red; run `make format` (pre-commit's ruff/prettier hooks write, not check).
3. vitest (`cd front && npm test`) is not in `make check`; `test-front` = typecheck + `next build` + bundle-size. Raise a budget only for an understood increase and record why in its `$comment`.
4. Version lives in two places: `front/package.json` `version` and the `APP_VERSION` env (`back/.env.example`, compose files). Backend exposes `settings.app_version` in `/healthz`; web gets `NEXT_PUBLIC_APP_VERSION` (`front/next.config.ts`).
5. `docs/openapi.json` is generated by `make docs`/`make docs-build` — never hand-edit. New docs page → add to `mkdocs.yml` `nav` (strict mode only logs INFO for unlisted pages).
6. Backend image keeps ffmpeg/ffprobe (media analysis) and a `pg_dump` ≥ the pgvector pg17 server (admin + scheduled backups; Debian's client 15 refuses).
7. Security/advisory bumps pin exact versions (`back/requirements*.txt`, `front/package.json` + lock); keep `eslint-config-next` equal to `next`.
8. Licence is Apache-2.0 (`LICENSE`); keep vendored notices (`third_party/opencut-classic/LICENSE`) and never hand-edit the generated wasm. No root `.github/`; don't add hosted CI.

## Recipes

**Add a check**: needs a DB → own make target; else add to `make check` and mirror it in `.pre-commit-config.yaml` (keep both in sync).

**Add a docs page**: a new page under `docs/` + `mkdocs.yml` `nav` → `make docs-build`.

## Verify

```bash
make check
make docs-build
make release-up
```
