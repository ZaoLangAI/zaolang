# Admin Ops — route map reference

One line per domain: router file in `back/app/api/v1/admin/` (all under `/v1/admin`) → page under `front/src/app/[locale]/(admin)/admin/(console)/` → components under `front/src/components/admin/`. Exact routes: grep `@router` in the router file.

- **Health** — `observability.py` `/health` (5 probes + queue depths + Alembic rev + LLM reachability), `/workflow` (declared pipeline shape for a job's timeline) → `/admin` → `health/health-cards.tsx`.
- **Job ops** — `jobs.py` `/jobs` (filters: status/user/provider/date/`origin`/`stuck_only`), `/jobs/stats` (declared before `/jobs/{job_id}`), `/jobs/{id}` + `/events` (`after_sequence` cursor) + `/stream` (admin SSE) + `/input-request` + `/answer` + `/terminate` + `/requeue`; `observability.py` `/jobs/{id}/routing`; `logs.py` `/logs?job_id=` (related logs) → `/admin/jobs` → `jobs/jobs-console.tsx`, `jobs/routing-replay-table.tsx`, `jobs/workflow-steps.tsx`.
- **Models / providers** — `llm_providers.py` `/llm-providers` (pool), `/llm-providers/catalog` (pre-fills `suggested_timeout_ms` + `generation_kind`), `PUT /{endpoint_id}`, `/remove`, `/validate` (+ poll `/validate/{validation_id}`); `observability.py` `/providers/stats` → `/admin/models` → `models/llm-providers-panel.tsx`: endpoints grouped 通用模型/媒体模型 by `kind` (no primary/backup lists); switching a new model's kind resets modalities and the default timeout (media 90 s); red badge = `circuit_breaker_open` incl. open `media_breaker` routes; vendor prices typed in USD or CNY, saved as micro-USD via `front/src/lib/admin/micro-usd.ts`.
- **Agents** — `agent_skills.py` `/agent-node-presets`, `/agent-nodes`, `/agent-profiles` (+ `PATCH`, `/disable`, `/delete`, `/debug-chat` SSE), `/agent-skill-tools`, `/agent-skill-templates`, `/agent-skills` (+ `/activate`); `observability.py` `/agent-runs/usage` → `/admin/agents` → `agents/agent-skills-panel.tsx`, `agents/agent-profile-dialog.tsx`, `agents/agent-debug-chat-dialog.tsx`.
- **Workflows** — `workflow_templates.py` `/workflow-templates/node-types`, `/validate`, `/{operation}` (GET/PUT, `asset_kind` query), `/{operation}/versions`, `/{operation}/activate/{template_id}`, `/{operation}/sandbox-run` (202 `{job_id}`), `/{operation}/sandbox-runs` (one row per try-it, never deduped) → `/admin/routing` → `workflows/workflow-editor.tsx`, `workflows/workflow-sandbox-dialog.tsx`, `workflows/workflow-sandbox-history-panel.tsx`, `workflows/sandbox-run-inspector.tsx`.
- **Statistics** — `statistics.py` `/statistics/*` → `/admin/statistics` → `statistics/statistics-workspace.tsx`. See zaolang-admin-statistics.
- **Moderation** — `content.py` `/moderation/queue` (+ `/{id}/detail` with embedded decision history, `/claim`, `/decide`), `/reports` (+ `/resolve`), `/appeals` (+ `/decide`), `/works/{id}/tombstone|hide|restore`, `/fingerprints/duplicates` (exact perceptual-hash matches) → `/admin/moderation` (tabs queue/reports/appeals; `/admin/reports` only redirects to `?tab=reports`) → `moderation/moderation-workspace.tsx`, `moderation/moderation-queue.tsx`, `moderation/duplicate-groups.tsx`, `reports/reports-console.tsx`, `appeals/appeals-console.tsx`, `subject-thumb.tsx`.
- **Learn posts** — `learning.py` `/learn-posts` (+ `/approve`, `/reject`) → `/admin/learn-posts` (`reviewer`) → `learn-posts/learn-posts-console.tsx`.
- **Skill library** — `skill_library.py` `GET /skills`, `POST /skills/{id}/takedown` (no feature/delist endpoint) → `/admin/skill-library` → `skill-library/skill-library-console.tsx`.
- **Style gallery** — `style_gallery.py` list/create/`PUT`/`/delete` + `/style-gallery/uploads/presign|complete` (cover upload via `front/src/lib/admin/upload.ts`) → `/admin/style-gallery` (`operator`) → `style-gallery/style-gallery-console.tsx`, `style-gallery/style-gallery-form-dialog.tsx`. Public reads + `/apply` counter: `back/app/api/v1/style_gallery.py`.
- **Users** — `users.py` `/users` (+ `/{id}`, `/suspend`, `/unsuspend`, `/roles`), `/data-requests` (+ `/decide`) → `/admin/users` → `users/users-console.tsx`, `users/role-editor.tsx`, `users/data-requests-panel.tsx`.
- **Credits** — `ledger.py` `/credits/ledger`, `/credits/reconciliation`, `/credits/dangling`, `/users/{id}/credits` (+ `/adjust`); `redemption.py` `/redemption-codes` (+ `/deactivate`, `/records`) → `/admin/credits` → `credits/ledger-console.tsx`, `credits/dangling-reserves.tsx`, `credits/redemption-codes-panel.tsx`. Semantics: zaolang-credits-billing.
- **Config** — `config.py` `/config` (+ `/{key}`, `/history`, `/diff`, `/rollback`; excludes `llm_providers`), `/feature-flags` → `/admin/config` (`operator`) → `config/runtime-config-panel.tsx`, `config/runtime-config-dialog.tsx`.
- **Announcements** — `config.py` `/announcements` (GET/POST) → `/admin/announcements` (`operator`) → `announcements/announcements-console.tsx`.
- **Data** — `data.py` `/storage/usage`, `POST /storage/lifecycle`, `/backups` (GET/POST), `/seed` (`reset` flag) → `/admin/data` (`operator`) → `data/backups-panel.tsx`, `data/lifecycle-panel.tsx`, `data/seed-panel.tsx`. Backup/retention semantics: zaolang-compliance-audit.
- **Log center** — `logs.py` `/logs` (audit + SystemLog merged); `config.py` `/audit-logs` (audit only) → `/admin/audit` → `audit/log-center-console.tsx`.
- **Auth** — `auth.py` `/auth/login|me|logout` → `front/src/app/[locale]/(admin)/admin/login/page.tsx`. See zaolang-admin-console.
