# 造浪 ZaoLang

全球 AI 图片与短视频二创共享平台。用户从「看见灵感」直接进入「创作新版本」，每一次二创都会留下版本化的创作链，继承原作者署名与许可快照。

## 五条不可妥协的约束

平台的其余部分都可以讨论，这五条不能：

1. **PostgreSQL 是唯一事实源。** 智能体的输出、供应商的回调、支付网关的通知，都必须落库之后才算发生过。
2. **默认「公开 · 仅展示」。** 二创授权必须由作者主动开启，不存在「默认允许」的路径。
3. **积分先预扣再结算。** 生成前 `reserve`，成功后 `capture` 实际消耗并释放差额，失败或取消必须 `release`。一次任务最多 `capture` 一次。
4. **删除不破坏后代溯源。** 父作品下线走隐藏或墓碑状态，创作链上的边永远保留。
5. **浏览器不直连外部服务。** 模型供应商、支付、对象存储的凭据只存在于后端。

## 当前实现边界

诚实地说清楚哪些是真的、哪些是骨架，比宣称「已完成」更有用：

- **智能体推理是真的。** 经 OpenAI 兼容网关（AIHubMix）接入真实模型，网关异常时自动降级到确定性 stub，降级次数与原因写入 `AgentRun`。
- **图片与视频生成不是真的。** 生成供应商仍是 `fake open` 与 `fake paid` 两条确定性路线；LLM 网关只服务智能体推理。
- **支付不是真的。** Mock 支付页配真实 HMAC 签名的 webhook，验签、时间窗、防重放、幂等都按生产标准实现，但没有接入 Stripe 生产环境。
- **语义检索用本地确定性向量。** 网关不提供 embedding 模型，`EmbeddingProvider` 保持可插拔，检索质量不代表真实向量模型水平。
- **C2PA 签名是接口预留位。** 生成输出会携带 AI 溯源清单，但没有做密码学签名。
