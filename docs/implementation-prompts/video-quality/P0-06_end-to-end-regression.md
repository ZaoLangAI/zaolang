# 完成视频质量闭环端到端验证与回归

## 仓库与边界

- 目标仓库：`/Users/mac001/project/zaolangai/zaolang`
- 本任务必须在 P0-01 至 P0-05 全部合并后执行；开始前重新阅读当前代码、迁移、OpenAPI、测试工具和工作树状态。
- 本任务以补测试、修复 P0 集成缺陷和完善文档为主，不扩展 P1/P2 功能。
- 不下载真实模型权重，不调用 H3、OpenVINO、DWPose、SEA-RAFT、VACE 或其他收费/ GPU 服务。
- 所有模型行为使用 fake provider、固定媒体技术夹具和模拟质量报告。
- 不重置共享数据库、不删除用户数据、不覆盖无关修改。
- PostgreSQL 继续是唯一事实源；积分、幂等、异步和发布不允许通过 mock 绕过领域逻辑。

## 已确认的源码事实

- 当前 H3 通过 `AiHubMixMediaProvider` 异步提交和轮询。
- H3 请求支持 4–15 秒、2K、首尾帧和图片/视频参考。
- 当前供应商请求不发送 `negative_prompt`，不得添加未经验证的 H3 请求字段。
- 当前 `quality_check` 只读取宽高、时长和供应商元数据，不能判断实际画面。
- 剧本 `breakpoint` 已经能携带片段文本、关联角色和场景进入视频工作室。
- 角色库已有参考图、声音描述和动作片段；场景库已有参考素材。
- 当前质量档为 `preview`、`standard`、`cinematic`。
- 当前生产容器没有 GPU 模型运行环境，独立模型必须通过硬件无关服务协议接入。

## 已确认的目标链路

```text
剧本 breakpoint
→ 角色/场景引用
→ H3 结构化提示词编译
→ preview/standard/cinematic 的 1/2/3 候选
→ 异步恢复
→ 内容级质量报告和自动推荐
→ 人工审核
→ 编辑器或发布
```

## 目标

证明 P0 新增协议、候选状态和产品门禁在不运行真实模型的条件下可以完整协作，同时保证当前上传、任务、积分、角色、场景、剧本、编辑器和发布行为零回归。

## 必须实现

1. 建立或完善可重复使用的：
   - fake H3 同步/异步结果；
   - fake analyzer 同步/异步报告；
   - fake processor 能力占位；
   - 小型合法 MP4、黑帧、坏容器、无音轨等固定夹具；
   - 多人身份、姿态和时序模拟报告。
2. 端到端覆盖：
   - 从剧本 breakpoint 生成视频创作输入；
   - 角色和场景引用进入 `ShotSpec`；
   - 提示词编译后进入 H3 请求；
   - 1/2/3 候选循环和异步恢复；
   - 技术硬门禁、内容报告、排序和推荐；
   - preview 自动采用与 standard/cinematic 人工门禁；
   - 审核候选进入编辑器和发布。
3. 建立 80 个逻辑样本的报告夹具清单，而不是生成 80 段真实视频：
   - 20 个近景/对白；
   - 15 个单人全身动作；
   - 20 个双人对话、握手、拥抱和遮挡；
   - 15 个三至四人及身份交换；
   - 10 个低光、快速转身、手持物和快运镜。
4. 对模拟标签实现统计测试：
   - 严重缺陷召回率；
   - 误拒率；
   - 自动推荐进入模拟人工首选的比例；
   - `unknown/not_assessable` 不被错误计为通过或严重失败。
5. 回归现有行为：
   - 上传和素材权限；
   - 报价、预扣、实际捕获、释放和预算上限；
   - 鉴权和幂等；
   - 异步轮询、取消、超时和 stale cleanup；
   - 角色多视角和动作片段；
   - 场景引用；
   - 剧本创建、修改、link 和 breakpoint；
   - 草稿、来源链、编辑器修订和发布。
6. 验证迁移从当前生产前一版本升级；若项目支持 downgrade，验证降级，否则明确记录不可降级原因和恢复方案。
7. 重新导出 OpenAPI 和前端 API 类型，确认仅出现已实现字段和端点。
8. 更新运维/架构文档，明确新增分析器队列、端点健康、许可证门禁、外发审计和故障降级。
9. 输出“真实模型未验证”清单，明确：
   - 没有测试真实 H3 提示词效果；
   - 没有测试真实人脸身份阈值；
   - 没有测试真实多人跟踪、姿态和光流；
   - 没有运行 GPU 推理；
   - 模拟指标不能作为上线质量指标。
