# 建立 Wan-Animate-2 动作生成实验路由

## 仓库与边界

- 目标仓库：`/Users/mac001/project/zaolangai/zaolang`
- 本任务只能在 P0 全部完成后执行，并默认属于实验/沙盒能力；开始前重新检查当前 provider、处理器、候选、质量和权限代码。
- 阅读适用的 `AGENTS.md`、README、供应商路由、沙盒运行、模型配置、许可证和成本测试。
- 不把 Wan-Animate-2、Diffusers、PyTorch 或 CUDA 安装进主 API 容器。
- 前端不得直连模型服务或裸 ComfyUI。
- PostgreSQL 是实验运行、候选、配置、成本、审计和评测记录的唯一事实源。
- 不下载权重，不调用真实 Wan-Animate-2，不执行 GPU 推理。
- 测试使用 fake provider 和固定参考图/驱动视频元数据。
- 不影响现有 H3 默认生产路由。
- 保留所有无关用户改动。

## 已确认的源码事实

- 当前 H3 通过 `AiHubMixMediaProvider` 异步提交和轮询。
- H3 请求支持 4–15 秒、2K、首尾帧和图片/视频参考。
- 当前供应商请求不发送 `negative_prompt`，不得添加未经验证的 H3 请求字段。
- 当前 `quality_check` 只读取宽高、时长和供应商元数据，不能判断实际画面。
- 剧本 `breakpoint` 已经能携带片段文本、关联角色和场景进入视频工作室。
- 角色库已有参考图、声音描述和动作片段；场景库已有参考素材。
- 当前质量档为 `preview`、`standard`、`cinematic`。
- 当前生产容器没有 GPU 模型运行环境，独立模型必须通过硬件无关服务协议接入。

## 本任务相关补充事实

- 当前 H3 是平台既有视频生成主路径。
- P0 应已提供候选、内容级质量报告、模型协议、外发策略和人工审核。
- Wan-Animate-2 的任务类型是“角色参考图 + 驱动视频 + 描述”的动作迁移/动画，不是普通 H3 文生视频参数。
- 该模型在本方案中必须保持 experimental，不得因为接口接通就进入生产。
- 当前平台的 ComfyUI 协议仍未实现，不能依赖裸工作流 JSON 作为产品接口。

## 目标

为拥有角色参考图和合法驱动视频的动作镜头建立 Wan-Animate-2 沙盒实验路由，记录完整制品和评测信息；在通过身份、动作、时序、成本和延迟验收前，不允许参与普通生产选路。

## 必须实现

1. 通过独立生成/媒体模型适配器接入，不复用 H3 请求构造器，不添加 H3 未支持字段。
2. 能力名称应表达业务意图，例如 `character_motion_transfer`，输入至少包含：
   - 单一目标角色参考图；
   - 已授权驱动视频；
   - 结构化人物外观和背景描述；
   - 画幅、目标时长和实验质量档；
   - 参考资产、剧集和用户权限信息。
3. 首期只支持单目标角色动作迁移；多人镜头不自动裁切或逐人合成，直接标记不支持。
4. 只有满足以下条件才能提交：
   - 管理端模型状态为 `experimental`；
   - 请求来源为沙盒/管理员实验或明确实验入口；
   - 剧集允许新增外部模型；
   - 角色参考和驱动视频拥有明确使用权限；
   - 端点 revision、许可证、运行时和价格已登记。
5. 适配器支持同步/异步提交、poll、取消和超时，并复用平台异步检查点、积分和审计原则。
6. 输出登记为独立实验候选，保存：
   - 父作业/来源；
   - 参考图和驱动视频来源；
   - 模型 revision、运行时和端点；
   - 参数、成本和延迟；
   - 内容级质量报告。
7. 实验候选必须经过 P0 完整的人脸身份、姿态、多人/单人轨迹、时序和技术质检，再进入人工盲评。
8. 普通 `route_score` 必须硬过滤 experimental 能力；只有显式实验路由能选中。
9. 管理端提供启用实验、禁用、查看验证状态和清除错误配置的操作，但不提供“一键生产启用”。生产启用必须是未来独立变更和评审。
10. 评测记录至少支持与同输入 H3 候选比较：
    - 身份；
    - 动作跟随；
    - 肢体完整性；
    - 时序稳定；
    - 背景保持；
    - 成本和延迟；
    - 人工偏好。
11. 官方源、许可证和模型 revision 必须登记；不能用第三方站点营销描述替代官方制品信息。

## 测试与验收

- fake Wan-Animate 同步/异步成功、失败、超时、取消和幂等。
- 无参考图、无驱动视频、多人输入、未授权素材和未授权剧集被拒绝。
- experimental 路由不能被普通用户生成任务选中。
- 实验候选完整保存来源、模型版本、成本、延迟和质量报告。
- H3 默认路由、报价、候选和发布零回归。
- 管理端不能通过普通启用开关绕过生产门禁。
- 测试和文档明确没有下载或运行真实 Wan-Animate-2。

- 不实现 ComfyUI JSON 工作流导入。
- 不支持多人动作迁移。
- 不自动将实验模型升级为生产模型。
- 不替代 H3 默认生成路径。
